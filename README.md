# cyber-toolkit

A collection of scripts and tools developed while learning cybersecurity, CTFs, and penetration testing.

## dwnld_scripts.py
Attempts to download all scripts from a certain html based website.
args: |url|
Author: Magnus Langhelle

## find_scripts.py
Attempts to find scripts inside of an html-based file. Could also be .txt file containing html info
args: |html|
Author: Magnus Langhelle
